# Windows 首次验收清单

当前构建为预览版，Linux 交叉编译不能验证 WPF 实际渲染与 Windows Shell 回收行为。以下必须在 Windows 本机完成，尚未勾选即表示未验收。

仅使用专门建立的测试目录。不要拿实际重要文件作为清理测试素材。所有移入回收站的测试文件应先有备份。

## 窗口与扫描

- [ ] Windows 10 22H2 / Windows 11 x64 启动，未安装 .NET 时仍可运行。
- [ ] 普通用户权限下启动，不出现管理员权限请求。
- [ ] 磁盘容量与资源管理器相符；不存在的盘符不显示。
- [ ] 1120×760 最小窗口、1360×920 和 125% / 150% DPI 下布局可操作。
- [ ] 选择含中文、空格及较长路径的测试文件夹；扫描大小及文件数与手工预期一致。
- [ ] 点击空间图和双击目录排行下钻；返回上级与根目录。
- [ ] 大文件按大小排序，名称与路径搜索、大小筛选正常。
- [ ] 扫描时窗口响应正常，取消后明确显示部分结果。
- [ ] 包含 Junction、符号链接、OneDrive 占位和无权限目录时安全跳过，详情可查。
- [ ] 存在超过 3 个盘符时，磁盘卡片水平滚动可见，不挤压结果区。

## 清理（只用测试副本）

- [ ] 新建个人文件，选中后先看到路径、大小和理由；未勾确认无法执行。
- [ ] 取消确认窗口不会修改文件；所有文件初始未选中。
- [ ] 勾选文件后修改其内容或修改时间：执行时跳过，原文件保留。
- [ ] 文件被其他程序独占占用：记录失败或跳过，应用仍可使用。
- [ ] 普通文件移入回收站后，原路径消失，**在回收站可以找到该文件**，然后执行“还原”并验证内容。
- [ ] 不同本地固定磁盘上的测试文件分别回收并还原。
- [ ] 可移动盘测试文件无法清理，原文件保持存在。
- [ ] **回收站关闭的磁盘、回收站配额不足、文件超出可回收大小**：必须拒绝或取消，不能永久删除。若出现异常，停止使用清理功能并保留日志。
- [ ] 通过 Shell “永久删除”路径或提示无法绕过回调保护；必须保留原文件。
- [ ] 清理时关闭主窗口被阻止，操作完成后可正常关闭。
- [ ] 移入回收站后界面不声称空间已释放；重新扫描后更新图表。

## 保护与记录

- [ ] Windows、Program Files、ProgramData、AppData 普通文件不可勾选。
- [ ] 当前用户 Temp 内新文件不可清理；至少 7 天未修改的普通测试文件可显示建议。
- [ ] 文件属性为隐藏、系统、只读或离线时不可勾选。
- [ ] `%LOCALAPPDATA%\DiskLens\History` 产生意图和逐项结果，重启后仍能查看。
- [ ] 记录目录不可写时，不执行回收操作。
- [ ] 手动中断测试进程后，未记录结果项目显示为“未记录结果”，不被当作已成功。

完成后记录 Windows 版本、构建版本、失败项目及对应日志。通过这份验收前，不应把此预览版视为可自动清理重要资料的正式产品。
