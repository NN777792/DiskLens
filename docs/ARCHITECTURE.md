# 实现与后续开发

## 模块

`DiskLens.Core` 不依赖 WPF 或 Windows Shell，因此扫描、目录聚合、清理策略和执行编排可在 Linux 上测试。`DiskLens.App` 负责 Windows 设备枚举、UI、文件夹选择、回收站与记录持久化。

主窗口使用 ViewModel 保存界面状态，命令处理目录导航与选择，异步事件负责扫描和清理。扫描器运行在后台线程；WPF Progress 在界面线程接收节流后的进度。Shell 操作通过专门 STA 线程执行，主窗口在操作完成前阻止关闭。

## 数据流

```text
磁盘/用户选定目录
    → DiskScanner（元数据、显式栈、不跟随链接）
    → ScanResult（目录树、Top 500 文件、临时建议、类型合计、跳过详情）
    → MainViewModel → 空间图 / 目录表 / 文件列表
    → 用户勾选 → 清单与确认
    → CleanupService
         → 写入意图并刷新到磁盘
         → 对每个文件重新验证策略与元数据
         → WindowsRecycler / IFileOperation（STA）
         → 持久化结果
    → 更新列表 / 提示重新扫描 / 查看回收站或历史
```

## 扫描

目录迭代发现顺序保证父节点在子节点前，逆序聚合大小和文件数，避免深目录递归栈溢出。文件 Top N 使用优先队列，只保留固定数量的最大项；不会把所有文件列表加载进 UI。目录树本身有 250,000 节点上限。重解析点和离线属性跳过，目录访问错误有界保留。

文件大小来自 `FileInfo.Length`，不冒充实际占用空间。不打开正文，不哈希，不安装后台服务，不请求全盘管理员权限。

## 保护与清理

路径判断使用规范化绝对路径和分隔符边界，Windows 忽略大小写。保护当前系统和应用数据路径；临时文件例外只有配置的当前用户 Temp 路径。清理前重新遍历父目录属性并核对大小和 UTC 修改时间。该校验并非以句柄绑定的防竞态实现，不能抵御恶意进程在检查后替换路径；文档与界面均说明边界。

Windows 回收站使用 `IFileOperation` 和每项进度回调，强制 recycle 标志，拒绝没有 recycle 传输标志的 PreDeleteItem。禁用连接文件联动处理，只删除用户勾选的单个普通文件；不递归删除目录。只对本地固定磁盘操作，检查 Shell 取消和完成状态。

操作日志先记录完整意图，再按项记录结果，写入后 `Flush(true)`。若程序异常退出，未记录结果的文件显示为未完成，需要用户核实实际状态。应用不宣称事务性回滚或自动还原。

## 后续优先级

1. Windows 10/11 真机验收：回收站关闭、容量不足、超大文件、文件锁、中文长路径、多显示器 DPI 和键盘导航。
2. 基于 Windows 文件身份（卷序列号与 File ID）的验证、实际占用查询与硬链接去重，处理路径竞态。
3. 扫描索引落盘，增量扫描和更完整的文件筛选；增加目录级用户保护名单。
4. 安装器、代码签名与版本更新，再考虑重复文件检测和空间增长比较。
