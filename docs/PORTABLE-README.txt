清简 · 磁盘助手 / DiskLens 0.1.0 预览版

运行要求：Windows 10 22H2 或 Windows 11，x64。
解压到本地文件夹后，双击 DiskLens.exe。无需安装 .NET，也无需管理员权限。

本版本在 Linux 上完成 Windows 交叉编译，核心回归测试全部通过。
WPF 窗口、Windows Shell 回收站尚未在 Windows 上实际验收。
请先使用专门的测试文件夹，并按 WINDOWS-ACCEPTANCE.md 进行验证。
此包尚未代码签名，不是正式发布版。

操作：
1. 选择磁盘或文件夹开始扫描；可随时取消。
2. 点击空间图或双击目录查看子目录；“大文件”页可筛选并打开所在位置。
3. 手动选择确认不需要的文件；“安全清理”页提供有限的临时文件建议。
4. 查看完整清单、核对用途并确认后移入回收站。
5. 恢复文件请在 Windows 回收站选择“还原”。

注意：
移入回收站通常不会立即增加磁盘可用空间。应用不提供永久删除或清空回收站。
文件大、长时间未修改，不能证明它可以安全删除。
图表是文件逻辑大小，硬链接、稀疏文件、压缩和跳过目录可能导致统计与已用空间不同。
扫描结果是快照；清理后请重新扫描更新图表。
最多保留最大的 500 个文件、2,000 个临时文件建议；每次最多发现 250,000 个目录。
可移动盘和网络位置仅分析，不清理。不跟随链接，不访问云盘占位项目。
临时建议仅针对当前用户 LocalAppData\Temp 内至少 7 天未修改的普通文件，全部默认不选中。
保护规则不能识别全部应用依赖；执行前的文件核对不能完全消除检查与操作间的竞态。

操作记录仅存储在本机 %LOCALAPPDATA%\DiskLens\History，包含文件完整路径。
扫描仅读取元数据，不读取正文或上传网络。首次启动会在用户临时目录解包原生运行库。
