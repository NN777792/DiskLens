DiskLens 磁盘清理助手 v1.1.1
================================

使用步骤：

1. 把下载的 DiskLens-win-x64.zip 完整解压到一个普通文件夹。
2. 打开解压得到的 DiskLens-win-x64 文件夹。
3. 双击 DiskLens.exe。

DiskLens.exe 已经包含程序和 .NET 运行环境，可以单独运行。README.txt 只是使用说明。

如果 Windows 显示“已保护你的电脑”，请点击“更多信息”，确认发布者和文件名后点击“仍要运行”。这是因为开源软件暂时没有商业代码签名。

程序默认以普通用户权限运行。清理的文件会进入 Windows 回收站。

垃圾清理功能会扫描临时文件、缩略图缓存、崩溃报告、DirectX 图形缓存和浏览器缓存。请先查看分类和预计释放空间，再勾选清理。

如果程序启动后报告错误，日志保存在：
%LOCALAPPDATA%\DiskLens\logs

系统要求：64 位 Windows 10 1809 或更高版本，推荐 Windows 11。
